# Bedienung

Für alle, die am Spieleabend mitspielen. Der Betreiber gibt euch eine Adresse (z. B. `https://spiele.deinedomain.de`), mehr braucht ihr nicht.

## Die drei Reiter

| Reiter | Inhalt |
|---|---|
| **Spiele** | Laufende Spiele, Live-Tisch beitreten, neues Spiel starten |
| **Spieler** | Mitspieler anlegen, umbenennen, Farbe wählen, Bilanz ansehen, archivieren |
| **Verlauf** | Entwicklung der Punkte über viele Partien, Rekorde, alle beendeten Spiele |

## Ein Spiel starten

1. Im Reiter **Spieler** die Mitspieler anlegen (einmalig, sie bleiben gespeichert).
2. Im Reiter **Spiele** das Spiel antippen, bei Bedarf Einstellungen wählen.
3. Die Spieler **in Spielreihenfolge** antippen (die Nummer zeigt die Reihenfolge, „Reihenfolge mischen“ lost sie aus).
4. Starten.

Ein Spiel läuft weiter, auch wenn du den Block schließt. Unter **Läuft gerade** geht es mit einem Tipp weiter. Ein Spiel, in dem noch nichts eingetragen wurde, wird beim Verlassen verworfen.

## Kniffel

* **Würfel-Eingabe:** Unten die Augen antippen oder **Würfeln** drücken. Sobald fünf Würfel liegen, zeigt jedes freie Feld seine Punkte; das beste ist eingekreist. Feld antippen, fertig. Einen Würfel antippen nimmt ihn heraus; „Würfeln“ wirft nur die leeren Plätze neu.
* **Summen-Eingabe:** Feld antippen und die Punkte tippen. Unmögliche Werte nimmt der Block nicht an. Über **0 · streichen** wird ein Feld gestrichen.
* Das **(i)** oder der Würfel links neben jedem Feld erklärt die Regel mit Beispiel.
* Oben rechts schaltest du zwischen Würfel- und Summen-Eingabe um, daneben liegt die **Übersichtstabelle** aller Spieler. Eine Zahl dort antippen springt zum Blatt dieses Spielers.
* **Varianten:** *Klassisch* (13 Felder, Bonus ab 63) und *Extreme* (17 Felder, Superbonus ab 80, jeder weitere Kniffel +100). Hausregeln im Einrichtungsbildschirm: Extra-Kniffel +50 (klassisch) und Erste Hand +5.

## Wizard

Für 3 bis 6 Spieler. Pro Runde: erst die **Ansagen** eintragen (sie dürfen zusammen nicht genau der Kartenzahl entsprechen), nach dem Spielen die **Stiche**. Der Block zeigt Geber und wer beginnt, rechnet die Punkte und zeichnet den Verlauf. Eine Runde antippen, um sie nachträglich zu ändern.

## Punktetafel

Für jedes Spiel ohne eigenen Block. **Runde eintragen**, für jeden Spieler die Punkte, mit dem Vorzeichen-Knopf auch Minuspunkte. Wertung „Höchste“ oder „Niedrigste gewinnt“, optional eine Zielpunktzahl: Wer sie erreicht, bekommt den Hinweis zum Auswerten.

## Rückgängig und Ende

* Nach jedem Eintrag erscheint kurz **Rückgängig**. Im Menü (⋯) steht der letzte Schritt ebenfalls bereit; so lassen sich nacheinander bis zu 60 Schritte zurücknehmen.
* **Jetzt auswerten** im Menü beendet das Spiel vorzeitig. Das passiert bei vollem Block von selbst.
* Das Ergebnis zeigt Rangliste und neue Rekorde. **Revanche** startet gleich das nächste Spiel, der nächste Spieler beginnt.
* **Spiel löschen** (im Menü) entfernt es aus Hauptmenü und Verlauf.

## Live-Tisch: gemeinsam auf mehreren Handys spielen

**Gastgeber:**
1. Spiel starten, im Menü (⋯) **Live-Tisch** → **Live-Tisch starten**.
2. Den fünfstelligen **Code** den anderen sagen oder über **Code kopieren** schicken.
3. Unter **Wer bist du?** den eigenen Platz wählen.

**Mitspieler:**
1. Block öffnen, Reiter **Spiele**, bei **Live-Tisch beitreten** den Code eintippen.
2. Den eigenen Namen wählen (**Das bin ich**).

Danach sieht jeder den Stand sofort und kann eintragen. Auch die Würfel sind geteilt: Wer würfelt oder Augen eingibt, zeigt allen den Wurf. Trägt jemand für einen anderen ein, ist das erlaubt: Es gibt bewusst keine Rechte, wer den Code kennt, schreibt mit. Der Gastgeber beendet den Tisch für alle; Mitspieler können ihn verlassen und behalten ihre Kopie. Ein Tisch, der länger nicht benutzt wird, verschwindet nach einigen Tagen von selbst. Dein Spielstand bleibt dir.

## Daten sichern, zweites Gerät, Handywechsel

Tippe oben auf **Gespeichert** (neben dem Titel):

* **Backup herunterladen / einspielen:** alle Spieler und Spiele als Datei.
* **Gerätekennung:** Dein Gerät erkennt dich an einer zufälligen Kennung. Auf einem zweiten Handy trägst du sie dort ein und hast dieselben Spieler und Spiele. **Gib sie nicht weiter** (wie ein Passwort). Wer sie notiert hat, kommt auch nach dem Löschen der Browserdaten wieder an alles.

## Status oben links

| Anzeige | Bedeutung |
|---|---|
| Gespeichert | alles liegt auf dem Server |
| Speichert … | wird gerade übertragen |
| Wartet auf Sync | kurz offline; nichts geht verloren, es wird nachgereicht |
| Nur lokal | Server nicht erreichbar; der Block läuft trotzdem und versucht es immer wieder |

## Als App installieren

Im Browser **Zum Home-Bildschirm** (iPhone: Teilen-Menü) bzw. **App installieren** wählen. Das geht nur, wenn die Adresse mit `https://` beginnt.
